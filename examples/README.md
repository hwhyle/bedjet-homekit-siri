# Example output

These files use obviously fake entity IDs. They show what
`generate_config.py` produces after a successful discovery.

- `discovered.example.json` — fixture for the helper scripts and CI
- `bedjet_siri.example.yaml` — generated Home Assistant package
- `homekit.example.yaml` — generated HomeKit YAML snippet

Do not copy these entity IDs into a live system. Run the discovery
scripts against your own Home Assistant instead.
